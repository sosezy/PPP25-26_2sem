# Функциональный API для работы с полигонами

Проект реализует ленивый API для генерации, преобразования, фильтрации, агрегации и визуализации плоских полигонов в функциональном стиле.

## План реализации

1. Описать единый формат данных:
полигон как tuple[tuple[float, float], ...];
последовательности полигонов как итераторы.
2. Реализовать базовые геометрические функции:
площадь;
периметр;
длины сторон;
проверка выпуклости;
проверка принадлежности точки полигону;
вычисление центра и расстояний.
3. Реализовать бесконечные генераторы последовательностей полигонов с использованием:
itertools.count;
map;
islice;
генераторов.
4. Реализовать трансформации как функции высшего порядка:
перенос;
поворот;
симметрия;
гомотетия.
5. Реализовать фильтры как функции, совместимые с filter.
6. Реализовать декораторы:
декораторы-трансформации;
декораторы-фильтры.
7. Реализовать агрегирующие функции через functools.reduce.
8. Реализовать дополнительные утилиты:
zip_polygons;
композицию функций;
функции применения фильтров и трансформаций.
9. Реализовать визуализацию последовательностей полигонов через matplotlib.

## Что реализовано

В проекте реализована визуализация последовательностей полигонов с использованием matplotlib, включая отображение фигур через matplotlib.patches.Polygon. Полигоны представлены как кортежи координат, а последовательности полигонов — как итераторы, что позволяет использовать ленивые вычисления и функциональный стиль обработки данных.

Реализованы бесконечные генераторы непересекающихся фигур: gen_rectangle, gen_triangle и gen_hexagon. Генераторы построены с использованием itertools.count, генераторов и функций высшего порядка, что позволяет создавать бесконечные последовательности полигонов и извлекать из них нужное количество фигур через itertools.islice.

Реализованы трансформации tr_translate, tr_rotate, tr_symmetry и tr_homothety, применяемые к последовательностям полигонов через map. Трансформации позволяют выполнять параллельный перенос, поворот, симметрию и масштабирование фигур без изменения исходных данных.
Реализованы все шесть фильтров из задания: flt_convex_polygon, flt_angle_point, flt_square, flt_short_side, flt_point_inside и flt_polygon_angles_inside. Все фильтры совместимы с функцией filter и позволяют выполнять выборку фигур по геометрическим свойствам.

Созданы и визуализированы сценарии из задания: три параллельные ленты полигонов, две пересекающиеся ленты, симметричные последовательности треугольников и последовательности четырёхугольников различного масштаба. Также реализованы сценарии применения фильтров к последовательностям фигур.

Реализованы декораторы на основе фильтров и трансформаций, позволяющие автоматически применять преобразования и фильтрацию к последовательностям полигонов, возвращаемым функциями. Это обеспечивает расширяемость и повторное использование логики обработки данных.
Добавлены агрегирующие функции agr_origin_nearest, agr_max_side, agr_min_area, agr_perimeter и agr_area, реализованные через functools.reduce. Функции позволяют вычислять суммарные и экстремальные характеристики последовательностей полигонов.
Дополнительно реализованы утилиты zip_polygons, apply_transform, apply_filter и compose. Функция zip_polygons объединяет несколько последовательностей полигонов в одну последовательность составных фигур, а функция compose позволяет строить композиции преобразований.

В проекте активно используются функции высшего порядка map, filter, reduce, модули itertools и functools, генераторы, итераторы, ленивые вычисления и композиция функций. Архитектура проекта является расширяемой и позволяет добавлять новые генераторы, фильтры и трансформации без изменения существующего кода.
